# Cached evidence

The committed rainfall snapshots are real public observations. The farmer groups, policies, claim statements, and payout amounts in `register/` are synthetic. All three initial claims use the same Lagos observation window to demonstrate memory across claims; they are not three independent weather cases.

`snapshots/ghcn/NIM00065201.csv` contains the original GHCN-Daily precipitation rows for July 2025, including the original measurement, quality, source and observation-time fields. The cached CSV is extracted from NOAA's [per-station archive](https://noaa-ghcn-pds.s3.amazonaws.com/csv/by_station/NIM00065201.csv). There are 10 reported days, 6.1 mm in total, and nine reported zeros. The other 21 days are absent, not zero. GHCN's tenths of a millimetre are converted exactly once by the query adapter. The station coordinates and elevation come from NOAA's [station inventory](https://www.ncei.noaa.gov/pub/data/ghcn/daily/ghcnd-stations.txt).

`snapshots/power/lagos_2025.json` preserves the NASA POWER response for independent `IMERG_PRECTOT` rainfall, requested at latitude 6.577 and longitude 3.321 for 1–31 July 2025, in UTC. Its 31 daily readings total 131.7 mm, rounded to one decimal place. The response geometry, source, fill value and API header remain attached. This is the independent IMERG series, not the gauge-corrected `PRECTOTCORR` series. [NASA request](https://power.larc.nasa.gov/api/temporal/daily/point?parameters=IMERG_PRECTOT&community=AG&longitude=3.321&latitude=6.577&start=20250701&end=20250731&format=JSON&time-standard=UTC).

`snapshots/power/lagos_prior.json` is the same independent series at the same point from July 2015 through July 2024. The calibration script selects complete July windows from the preceding 10 years, never the claim year. Their median is 206.12 mm. The synthetic policy trigger is 70% of that median, or 144.3 mm; the exit is 30%, or 61.8 mm. These fractions are explicit demonstration contract assumptions, not actuarially validated pricing. `register/calibration.json` records the yearly totals and method. Run `npx tsx scripts/climatology.ts data/snapshots/power/lagos_prior.json 2025-07-01 2025-07-31` to reproduce the calculation.

The sample query adapter loads these files into an in-memory DuckDB database with `pluvia.policies`, `pluvia.claims`, `pluvia.stations`, `pluvia.ghcn_prcp`, `pluvia.power_lagos_2025_daily` and `pluvia.power_lagos_2025_prior_daily`. It executes the same SQL emitted by the live DataAgent. The model adapter uses deterministic rules labelled `sample-rules`; it is not a Nemotron response or a recorded live model call. Probes, policy rules, payout calculation, trace writing and H-MEM are the real application code.

The cached sources were downloaded on 26 October 2026. The original NASA response remains unmodified. The station CSV contains only the selected real rows and header. Missing, flagged, duplicate and fill readings remain unavailable when the application checks them. The data can show that a record cannot settle a claim; it cannot identify a physical instrument failure or establish the loss on a farm.
